# Location: Medbay

**ID:** medbay
**Status:** CANON

## Overview

Primary medical and cognitive audit facility on Deck C of the *Mnemosyne*. Sterile lighting, persistent low hum from diagnostic beds.

## Sensory Profile

Antiseptic smell. Blue-white panels. Privacy screens that never fully mute adjacent conversations.

## Plot Relevance

Sera's base of operations. Memory audit terminals access the ship's MnemoArchive.

## Connected Factions / Characters

- Sera Voss (primary)
- Ship Medical Directorate
