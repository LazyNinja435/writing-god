# World Rule: Memory Audit Protocol

**ID:** memory-audit-protocol
**Status:** CANON

## Rule Statement

All crew memory logs in MnemoArchive are immutable once certified by two medical officers—except under Captain's Emergency Clause 17.

## Scope

Applies to all archived episodic memories uploaded from neural lace interfaces.

## Limitations / Costs

Emergency edits require dual authorization and create an audit trail entry visible to Medical Directorate.

## Exceptions

Clause 17 has been invoked twice in ship history; both instances are classified in the captain's ledger.
