# Prepare Agent Brief

## Purpose

Package focused inputs for a specialist agent role.

## When to Use

- Delegating to continuity-editor, prose-writer, etc.
- Multi-agent review panel

## Required Inputs

- Target agent definition
- Task scope
- Context bundle from load-book-context

## Workflow

1. Load agent Allowed/Not Allowed boundaries
2. Attach only inputs the agent expects
3. Include output format requirements
4. State explicit constraints from rules

## Output

Agent brief document or structured handoff

## Forbidden

- Including unrelated context
- Omitting authority boundaries
