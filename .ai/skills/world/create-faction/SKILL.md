# Create Faction

## Purpose

Define a group, institution, or faction.

## When to Use

- Political/social plot needs

## Required Inputs

- Faction goals
- Key members
- Relationships

## Workflow

1. Write faction template
2. Link to locations and characters

## Output

canon/factions/<slug>.md

## Forbidden

- Faction capabilities that break world rules
