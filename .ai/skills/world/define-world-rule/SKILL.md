# Define World Rule

## Purpose

Document a magic/tech/social rule.

## When to Use

- Speculative fiction worldbuilding

## Required Inputs

- Rule scope
- Limitations
- Costs

## Workflow

1. Write world rule template
2. Note exceptions
3. Status PROPOSED

## Output

canon/world/<rule-slug>.md

## Forbidden

- Rules without limitations
- Silent changes to established rules
