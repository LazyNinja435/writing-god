# Create Location

## Purpose

Define a named location.

## When to Use

- Scene needs new or detailed location

## Required Inputs

- Location role
- Sensory and practical details

## Workflow

1. Write location template
2. Link factions/characters present
3. Status PROPOSED until promoted

## Output

canon/locations/<slug>.md

## Forbidden

- Geography that contradicts established map

## Related

- Templates: location.template.md
