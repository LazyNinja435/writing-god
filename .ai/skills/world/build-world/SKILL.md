# Build World

## Purpose

Establish foundational world context.

## When to Use

- Bible phase
- New book in speculative genre

## Required Inputs

- Genre packs
- Premise needs
- Story scale

## Workflow

1. Document geography, institutions, constraints
2. Create index in canon/world/
3. Link locations and factions

## Output

canon/world/ index and initial world files

## Forbidden

- Over-building irrelevant detail
- Violating genre without book config
