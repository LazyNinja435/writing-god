# Track Setup Payoff

## Purpose

Register and monitor setup/payoff pairs.

## When to Use

- Planting foreshadowing
- Before act review

## Required Inputs

- Scene or outline with setup elements
- Existing setup-payoff registry

## Workflow

1. Record setup ID, location, intended payoff
2. Link to threads
3. Update setup-payoff registry

## Output

planning/setup-payoff/<id>.md

## Forbidden

- Paying off without recorded setup
- Orphan setups with no plan
