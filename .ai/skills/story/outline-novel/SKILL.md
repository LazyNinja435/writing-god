# Outline Novel

## Purpose

Create macro story architecture.

## When to Use

- Bible approved
- Moving from concept to structure

## Required Inputs

- Story bible
- Genre packs
- book.yaml structure model

## Workflow

1. Define acts and major turning points
2. Map main plot and subplots
3. Document in planning/architecture.md
4. Create thread stubs

## Output

planning/architecture.md and thread files

## Forbidden

- Writing scene prose
- Resolving every thread in outline phase

- Templates: story-architecture.template.md
