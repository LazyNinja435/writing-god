# Track Story Threads

## Purpose

Create or update a plot thread.

## When to Use

- New subplot or mystery introduced
- Thread state changes

## Required Inputs

- Thread description
- Related characters
- Initial state

## Workflow

1. Assign thread ID
2. Set state: introduced/active/etc.
3. Link scenes that touch thread

## Output

planning/threads/<thread-id>.md

## Forbidden

- Resolving threads without explicit event
- Duplicate thread IDs

## Related

- Templates: story-thread.template.md
- Rules: canon/timeline-consistency.md
