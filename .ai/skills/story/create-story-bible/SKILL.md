# Create Story Bible

## Purpose

Compile foundational story reference.

## When to Use

- After premise approval
- Before macro outlining

## Required Inputs

- Approved premise
- Initial characters and world notes

## Workflow

1. Gather premise, themes, narrative-style
2. Index character and world canon paths
3. Document POV and tense from book.yaml
4. Create bible index in canon/

## Output

Story bible index linking canon artifacts

## Forbidden

- Writing full manuscript in bible phase
- Establishing plot outcomes not yet in planning
