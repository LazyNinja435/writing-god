# Define Themes

## Purpose

Identify and document thematic through-lines.

## When to Use

- Story bible creation
- Developmental review flags weak theme

## Required Inputs

- Premise
- Character arcs
- Genre pack guidance

## Workflow

1. List primary and secondary themes
2. Link themes to character arcs and plot
3. Write themes.md

## Output

books/<book>/canon/themes.md

## Forbidden

- Declaring themes that contradict approved premise
