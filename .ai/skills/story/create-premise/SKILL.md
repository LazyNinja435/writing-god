# Create Premise

## Purpose

Articulate the core story premise.

## When to Use

- New book initialization
- Premise is missing or rejected

## Required Inputs

- Story concept
- Genre configuration
- Target audience

## Workflow

1. Extract central conflict
2. Define protagonist situation
3. State stakes
4. Write premise.md using template
5. Flag for human approval if configured

## Output

books/<book>/canon/premise.md (status PROPOSED until approved)

## Forbidden

- Locking premise as CANON without approval
- Over-specifying plot beats in premise
