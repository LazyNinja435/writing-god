# Plan Scene

## Purpose

Create executable scene card from outline.

## When to Use

- Before prose writing
- Outline-to-scene-graph phase

## Required Inputs

- Chapter outline beat
- Thread states
- POV assignment

## Workflow

1. Fill scene card template
2. Define goal, conflict, turn, outcome
3. List information revealed/withheld
4. Set prohibited reveals

## Output

planning/scenes/<scene-id>.yaml

## Forbidden

- Leaving outcome ambiguous
- Approving reveals that violate thread plan
