# Revise Scene

## Purpose

Revise prose based on review findings.

## When to Use

- Review returned revise action
- CHANGE_REQUEST approved

## Required Inputs

- Scene draft
- Review findings
- Scene card

## Workflow

1. Address findings by severity
2. Preserve approved outcomes
3. Re-run continuity checks

## Output

Revised manuscript scene

## Forbidden

- Using revision to change plot without approval
