# Propose Canon Change

## Purpose

Formal proposal to establish or change permanent CANON (separate from narrative state events).

## When to Use

- After an approved scene suggests a canon-worthy fact
- Conflict detected with existing CANON
- Approved retcon needed

## Required Inputs

- Fact text and justification
- Evidence (scene/event citations)
- Proposed resolution if conflict

## Workflow

1. Document proposed fact with status `PROPOSED`
2. Store under `canon/proposals/`
3. Route to canon-curator / `continuity/canon-update`
4. Require human approval for major changes / retcons

## Output

Canon proposal per template/schema

## Forbidden

- Silent retcon
- Writer self-approving canon
- Treating state-event deltas as permanent CANON
