# Propose Canon Change

## Purpose

Formal proposal to change established canon.

## When to Use

- Conflict detected
- Approved retcon needed

## Required Inputs

- Contradiction evidence
- Proposed resolution

## Workflow

1. Document conflict
2. Propose options
3. Route to canon-curator
4. Require human approval for major changes

## Output

canon proposal per template

## Forbidden

- Silent retcon
- Writer self-approving canon
