# Design Character Arc

## Purpose

Plan character transformation arc.

## When to Use

- Architecture or bible phase

## Required Inputs

- Character canon
- Theme links
- Plot role

## Workflow

1. Define want, need, flaw, ghost
2. Map arc beats across acts
3. Write arc document

## Output

planning or canon/characters/<slug>-arc.md

## Forbidden

- Arc that requires unapproved plot changes
