# Validate Character Behavior

## Purpose

Check actions against character profile and knowledge.

## When to Use

- Continuity review
- Before approving scene

## Required Inputs

- Character canon
- Knowledge state
- Proposed actions/dialogue

## Workflow

1. Compare behavior to motivations and flaws
2. Check knowledge boundaries
3. Flag inconsistencies

## Output

Validation notes or review findings

## Forbidden

- Rewriting scene during validation
