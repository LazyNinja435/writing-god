# Create Character

## Purpose

Define a new character in canon.

## When to Use

- New character needed for plot
- Bible phase

## Required Inputs

- Role in story
- Relationships
- Arc needs

## Workflow

1. Write character file from template
2. Set status PROPOSED
3. Link to relationships

## Output

canon/characters/<slug>.md

## Forbidden

- Establishing CANON status without workflow
- Contradicting existing character canon
